## Lab 10: Advanced Git & DevOps Pipeline Workflow
* **Description:** Modeling an enterprise cloud infrastructure workflow using advanced repository management controls. This includes implementing a feature branch layout, applying hotfixes directly to production, rebasing downstream code tracks across shifting upstream timelines, staging dirty tree layouts via the Git stash memory shelf, establishing multi-cloud resilience tracking, cutting release tags, and simulating surgical rollbacks.
* **Key Skills Exhibited:** Upstream timeline rebasing, Git stash lifecycle isolation, multi-remote targeting (`origin` vs `backup`), immutable annotated semantic tagging (`v1.0`), non-destructive atomic repository rollback via `--soft` resets.
